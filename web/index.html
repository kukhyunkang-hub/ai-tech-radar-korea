• 하이브리드 비용 절감 공식: 초기 UI와 Supabase DB 뼈대는 Lovable($20/월, 메시지당 1차감)로 빠르게 생성한 뒤, GitHub 동기화를 통해 코드를 로컬로 가져와 Cursor($20/월, 500 Fast + 무제한 Slow) 또는 Windsurf($15/월)에서 세부 디버깅을 진행하면 추가 과금을 100% 방어할 수 있습니다.

• AI 영상(Runway · Kling AI): 텍스트 프롬프트만으로 바로 영상을 생성(Text-to-Video)하면 구도가 마음에 들지 않아 4~5번 재촬영하며 크레딧을 낭비하게 됩니다. 반드시 이미지 생성 툴로 첫 프레임 이미지를 먼저 확정한 뒤 Image-to-Video로 모션만 부여하세요.

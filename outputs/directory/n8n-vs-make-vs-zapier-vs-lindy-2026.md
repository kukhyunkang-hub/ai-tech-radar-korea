## 💰 2. 실전 시뮬레이션: "10단계 워크플로우를 월 1,000회 실행하면 얼마가 나올까?"

단순히 "웹훅 수신 → 데이터 가공 → AI 텍스트 분류 → DB 저장 → 슬랙 알림" 등 **10개 단계(트리거 1개 + 액션 9개)로 구성된 실무 워크플로우를 한 달에 1,000번 실행**한다고 가정해 보겠습니다. 과금 단위의 차이가 어떻게 월 구독료 격차로 이어지는지 적나라하게 드러납니다.

### 💡 핵심 인사이트: 왜 Zapier 유저들이 Make와 n8n으로 대거 이탈하는가?
- **Zapier의 함정:** Zapier 무료 플랜은 오직 **2단계(트리거 1 + 액션 1)**만 허용합니다. 실무에 필수적인 3단계 이상 멀티스텝을 쓰려면 무조건 유료(Professional 월 $19.99~29.99)로 올려야 하는데, 주어지는 한도는 고작 **월 750 Tasks**뿐입니다. 단계가 늘어날수록 Task가 곱절로 증발합니다.
- **Make로의 전환 효과:** 동일한 멀티스텝 자동화를 [**Make Core 플랜($9/월)**]({{AFFILIATE_LINK_MAKE}})으로 옮기면 월 10,000 Credits가 제공되어 체감 비용이 **1/5 이하로 감소**하며, 라우터(Router)와 필터(Filter) 모듈은 무료로 처리됩니다.
- **n8n의 압도적 스케일:** 데이터 수백 건을 반복문(Loop)으로 돌리거나 20~50단계의 복잡한 AI 에이전트 파이프라인을 구축할 때는 모듈마다 과금되는 방식도 부담스러울 수 있습니다. 이때 [**n8n Cloud Starter(€20/월)**]({{AFFILIATE_LINK_N8N}})를 쓰면 단계가 아무리 길어도 **워크플로우 1회 완주에 단 1 Execution**만 차감되므로 대규모 자동화에서 적수가 없습니다.

## ⚠️ 4. 결제 전 반드시 알아야 할 각 툴의 치명적 단점 (Cons) 솔직 리뷰

완벽한 툴은 없습니다. 우리 회사(AI Tech Radar)는 독자가 결제 후 후회하거나 문의(CS)하는 일을 막기 위해 각 툴의 단점을 투명하게 공개합니다.

### ① Make.com의 단점
- **초기 시각적 학습 곡선:** 자피어(Zapier)처럼 단순 일직선 리스트가 아니라 2차원 캔버스에 원형 모듈을 연결하고 JSON/배열(Iterator, Aggregator) 개념을 이해해야 하므로 첫 1~2시간의 학습이 필요합니다.
- **대량 루프 시 크레딧 소모:** 1,000줄짜리 구글 시트 행을 하나씩 순회하며 처리하면 모듈 작동 횟수만큼 Credits가 차감되므로, 대량 데이터 배치 처리에는 n8n보다 불리합니다.
- **대안:** 대량 루프 작업이 많다면 [**n8n Cloud**]({{AFFILIATE_LINK_N8N}})를 병행하세요.

### ② n8n의 단점 (Self-hosted vs Cloud 현실 비교)
- **비개발자에게 높은 진입장벽:** 데이터 구조(JSON 표현식)와 웹훅/API 개념을 조금이라도 알아야 100% 위력을 발휘합니다.
- **"셀프호스팅 무료"의 숨겨진 비용:** n8n Community Edition은 자체 서버(Docker/VPS)에 무료로 설치할 수 있지만, **서버 비용 자부담 + 버전 업데이트 충돌 해결 + 보안/SSL 인증서 관리 + 서버 다운 시 복구**를 본인이 직접 해야 합니다.
- **시급 아끼는 팁:** 개발자라 하더라도 인프라 관리에 쓰는 내 시급을 계산해 보면, 커피 몇 잔 값인 **월 €20(~$20)를 내고 무제한 단계 2,500 Executions와 자동 업데이트를 보장받는 [n8n Cloud Starter]({{AFFILIATE_LINK_N8N}})를 쓰는 것이 압도적으로 이득**입니다.

### ③ Zapier의 단점
- **살인적인 멀티스텝 가성비:** 무료 플랜은 2-step으로 묶여 있고, 유료 플랜(월 $19.99~$29.99)도 750 Tasks에서 시작해 자동화 규모가 조금만 커져도 월 $100 이상 청구됩니다.
- **대안:** 이미 Zapier 유료 결제를 고민 중이라면 [**Make Core($9/월)**]({{AFFILIATE_LINK_MAKE}})로 똑같은 워크플로우를 반값 이하에 구현할 수 있는지 먼저 확인하세요.

### ④ Lindy.ai의 단점
- **영구 무료 플랜 부재 및 크레딧 소멸:** 영구 무료 티어가 폐지되고 **7일 무료 체험(Free Trial)**만 제공됩니다. 또한 Plus($29.99/월, 3,000 Credits) 등 유료 플랜에서 **이번 달에 다 쓰지 못한 잔여 크레딧은 다음 달로 이월(Rollover)되지 않습니다.**
- **복잡한 작업의 크레딧 차감 폭:** 단순 요약/답장은 2~250 크레딧이지만, 심층 리서치나 무거운 티켓 처리는 작업당 250~1,000 크레딧이 소모될 수 있습니다. 결제 전 반드시 [**Lindy.ai 7일 무료 체험**]({{AFFILIATE_LINK_LINDY}}) 기간 동안 본인의 실제 워크플로우 크레딧 소모량을 먼저 테스트해 보시길 권장합니다.
